# Nimra Safdar — Data Science & AI Portfolio

A responsive, single-page portfolio website built with plain HTML, CSS, and JavaScript. It is suitable for GitHub Pages, Netlify, or any static hosting provider.

## Files

- `index.html` — website structure and portfolio content
- `style.css` — layout, responsive styling, colors, and animations
- `script.js` — mobile navigation, scroll progress, reveal effects, headline rotation, and copy-email interaction

## Run locally

1. Download and extract the ZIP file.
2. Open the `nimra-portfolio` folder.
3. Double-click `index.html` to preview it in your browser.

You can also open the folder in Visual Studio Code and use the Live Server extension.

## Deploy on Netlify

1. Extract the ZIP file.
2. Open Netlify and sign in.
3. Choose **Add new site** / **Deploy manually** (the wording may vary).
4. Drag the `nimra-portfolio` folder into the deployment area. Make sure `index.html`, `style.css`, and `script.js` are at the top level of the folder.
5. Netlify will publish the site and provide a public URL.

## GitHub upload

Create a new repository (for example, `nimra-portfolio`), then upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root. Do not upload the ZIP as the only repository content if your teacher needs to inspect the source files.
